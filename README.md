# Touch-ID-restart-app
Утилита для macOS, позволяющая быстро перезапускать Touch ID без ввода пароля при каждом запуске. Поддерживает пользовательский и системный перезапуск служб Touch ID, а также полный сброс отпечатков. Простая установка и настройка через shell-скрипты с минимальными привилегиями.
